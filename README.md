# 歴史カードバトル（テスト版 v0.4）

マーベルスナップ風の「3つの場所の陣取り」カードゲーム。カード効果と史実コンボで、人物と出来事のつながりを覚える。
仕様は [SPEC.md](SPEC.md)。

## あそぶ
- 開発中：`index.html` をブラウザで開く
- 配布用：`dist/rekishi-card.html`（画像・音・フォント入りの1ファイル。HTML直配布用）

## ファイル
| ファイル | 中身 |
|---|---|
| src/data.js | カード・デッキ・場所のデータ（効果の数値・歴史メモもここ） |
| src/engine.js | ルール（画面と切りはなし。2台対戦でも同じ処理を使う予定）とCPU |
| src/ui.js | 画面・ドラッグ/クリック操作・演出 |
| src/style.css | 見た目（横1280×720／縦480×960を基準に拡大縮小） |
| lib/se.js | 効果音（eitan から流用） |
| img/ | manabi-historia の素材を流用 |
| tools/sim.js | CPUどうしの対戦でバランス確認：`node tools/sim.js 2000` |
| tools/shot.py | 4つの画面サイズでスクショ＋はみ出し・かぶり・画面外チェック |
| tools/dragtest.py | ドラッグ・クリック・タップ操作の確認 |
| tools/build.py | 配布用1ファイルHTMLを作る：`python3 tools/build.py` |
