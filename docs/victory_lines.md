# 勝利セリフ一覧（案）

勝ったデッキの主役が話す。上から優先して選ぶ：
**因縁の相手 → 勝ち方（宣言・コンボ・大差・ぎりぎり）→ 相手の時代（古い／新しい）→ ふつう（ランダム）**

- 大差：2つの場所でどちらも10以上の差／ぎりぎり：取った場所のどちらかが1〜2の差
- 同じ条件に2本以上あるときはランダム
- 2人デッキ（中大兄・鎌足／家光・家康／西郷・勝）は、セリフの前に話す人を書いてある
